# Экраны приложения

## 1. /login 

**Заголовок:** Введите номер телефона  
**Подзаголовок:** Чтобы получить доступ к календарю объектов

### Элементы:

- **Поле ввода телефона**
  - Тип: `tel`
  - Placeholder: `+7 999 585-13`
  - Маска: `+7 (XXX) XXX-XX-XX`

- **Кнопка "Войти"** 
  - **Action:** `POST /auth/login`
  - **Request body:**
    ```json
    { "phone": "+79995851338" }
    ```
  - **Success redirect:** `/verify`
  - **Error:** показать сообщение под кнопкой

- **Ссылка "Политика конфиденциальности"**
  - **Action:** переход на `/privacy-policy`

---

## 2. /verify 

**Заголовок:** Введите код подтверждения  
**Текст:** Мы отправили вам смс с кодом на номер +7 999 585-13-38

### Элементы:

- **Кнопка "Назад"**
  - **Action:** `GET /login`

- **Поле ввода кода**
  - Тип: 6 цифр
  - UI: 6 ячеек с точками (• • • • • •)
  - Автофокус на первое поле

- **Кнопка "Подтвердить"** 
  - **Action:** `POST /auth/verify`
  - **Request body:**
    ```json
    { "phone": "+79995851338", "code": "123456" }
    ```
  - **Success redirect:**
    - Если пользователь существует → `/objects-list`
    - Если новый пользователь → `/register`
  - **Error:** показать сообщение "Неверный код"

- **Ссылка "Отправить ещё раз"**
  - **Initial state:** disabled (3 секунды)
  - **Timer:** "Доступно через 3 секунды"
  - **Action:** `POST /auth/resend-code`
  - **Request body:**
    ```json
    { "phone": "+79995851338" }
    ```

      "address": "ул. Машинная, д. 31Д",
      "schedule": [
        { "start": "10:00", "end": "16:00" },
        { "start": "08:00", "end": "09:00" }

  - **Action:** открыть всплывающее окно подтверждения удаления
  - **Route:** `/object/:id/delete`

## API Endpoints Summary

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/auth/login` | Вход по номеру телефона |
| POST | `/auth/verify` | Подтверждение SMS-кода |
| POST | `/auth/resend-code` | Повторная отправка кода |
| POST | `/auth/register` | Регистрация нового пользователя |
| POST | `/auth/logout` | Выход из аккаунта |
| GET | `/objects-list` | Получить список объектов |
| POST | `/object` | Добавить новый объект |
| PATCH | `/object/:id` | Редактировать объект |
| DELETE | `/object/:id` | Удалить объект |
| PATCH | `/object/:id/favorite` | Добавить/убрать из избранного |
| PATCH | `/object/:id/marketplaces` | Обновить маркетплейсы объекта |
| PATCH | `/object/:id/employees` | Обновить сотрудников объекта |
| GET | `/employees` | Получить список сотрудников |
| POST | `/employee` | Добавить сотрудника |
| PATCH | `/employee/:id` | Редактировать сотрудника |
| DELETE | `/employee/:id` | Удалить сотрудника |
| GET | `/calendar` | Получить календарь объекта |
| POST | `/calendar/:date/shift` | Добавить смену |
| DELETE | `/calendar/:date/shift/:shift_id` | Удалить смену |
| POST | `/calendar/shifts/copy` | Размножить смены |
| GET | `/chats` | Получить список чатов |
| GET | `/chat/:id` | Получить сообщения чата |
| POST | `/chat/:id/message` | Отправить сообщение |
