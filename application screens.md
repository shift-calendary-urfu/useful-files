## Общие правила

### Сеть и формат данных

- **Base URL** для всех запросов: `/api/v1`.
- Все запросы, кроме `/auth/*`, требуют заголовок:

- Формат данных — **JSON** (`Content-Type: application/json`).

---

### Авторизация

- Авторизация осуществляется исключительно по номеру телефона через **SMS**.
- Email и пароли не используются.

---

### Часовые пояса

- Часовые пояса **не выводятся** в интерфейсе и **не редактируются**.
- На бэкенде используется единый зашитый часовой пояс.

---

### Смены

- Ночные смены (переход через полночь) **не поддерживаются**.
- Все смены должны начинаться и заканчиваться в пределах одних календарных суток.

---

### Исключено из MVP

Следующие функции требуют отдельного проектирования в будущих спринтах:

- Чаты
- Избранное
- Push-уведомления
- Массовая генерация смен

## 1. `/login` — Вход по номеру телефона

**Заголовок:** Вход  
**Подзаголовок:** Чтобы получить доступ к календарю рабочих точек

### Элементы

- **Поле «Телефон»**
- Тип: `tel`
- Placeholder: `+7 (XXX) XXX-XX-XX`
- Валидация: обязательное, корректный номер телефона

- **Кнопка «Получить код»**
- **Action:** `POST /api/v1/auth/send-code`
- **Request body:**

  ```json
  {
    "phone": "+79995851338"
  }
  ```

- **Success:** переход на `/verify`
- **Error:** показать сообщение под кнопкой

- **Ссылка «Политика конфиденциальности»**
- **Action:** переход на `/privacy-policy`

## 2. `/verify` — Подтверждение SMS-кода

**Заголовок:** Подтверждение номера телефона  
**Текст:** Мы отправили код подтверждения на номер +7 999 585-13-38

### Элементы

- **Кнопка «Назад»**
- **Action:** переход на `/login`

- **Поле ввода кода**
- Тип: 4 или 6 цифр
- UI: ячейки для ввода
- Автофокус на первое поле

- **Кнопка «Подтвердить»**
- **Action:** `POST /api/v1/auth/verify-code`
- **Request body:**

  ```json
  {
    "phone": "+79995851338",
    "code": "123456"
  }
  ```

- **Success (существующий пользователь):** сохранить `access_token`, редирект на `/workplaces`
- **Success (новый пользователь):** сохранить `access_token`, редирект на `/onboarding`
- **Error:** «Неверный код»

- **Ссылка «Отправить код ещё раз»**
- **Initial state:** disabled, таймер обратного отсчета
- **Action:** `POST /api/v1/auth/send-code`

## 16. `/reports` — Отчетность за месяц

**Заголовок:** Отчет за месяц

### Элементы

- **Кнопка «Выбрать точку»**
- **Action:** открыть `/workplace-select`

- **Селект периода**
- Выбор месяца и года

- **Загрузка данных**
- **Action:** `GET /api/v1/reports/monthly`
- **Query params:** `workplace_id`, `year`, `month`

- **Список сотрудников (Карточка)**
- ФИО сотрудника
- Отработано смен (целое число)
- Отработано часов (общее время)
- Дополнительные часы (переработки)

**Логика расчета (на стороне Backend):**
1. Если время смены сотрудника полностью совпадает с графиком работы ПВЗ, засчитывается 1 смена.
2. Если сотрудник отработал меньше графика ПВЗ, смена не засчитывается, учитываются только фактические часы.
3. Если сотрудник отработал дольше графика ПВЗ, засчитывается 1 полная смена плюс фиксируются дополнительные часы переработки.
4. Шаг расчета времени строго ограничен 30 или 60 минутами. Плановый и фактический график не разделяются (актуальный график является фактом).

- **Bottom Navigation Bar**
- Активна вкладка «Отчеты»

## Согласование названий запросов

| Экран / действие | Было в первоначальных экранах | Стало по спецификации MVP |
|---|---|---|
| Вход | `POST /auth/login` (email, password) | `POST /api/v1/auth/send-code` (phone) |
| Подтверждение | `POST /auth/verify` | `POST /api/v1/auth/verify-code` |
| Регистрация | `POST /auth/register` | `PUT /api/v1/users/me/onboarding` |
| Список объектов | отсутствовал | `GET /api/v1/workplaces/` |
| Создание объекта | `POST /object` | `POST /api/v1/workplaces/` |
| Редактирование объекта | `PATCH /object/:id` | `PUT /api/v1/workplaces/{workplace_id}` |
| Удаление объекта | `DELETE /object/:id` | `DELETE /api/v1/workplaces/{workplace_id}` |
| Избранное | `PATCH /object/:id/favorite` | Исключено из MVP |
| Сотрудники точки | `PATCH /object/:id/employees` | `GET /api/v1/workplaces/{id}/employees`, `POST /api/v1/employees/`, `DELETE /api/v1/employees/{id}` |
| Добавление сотрудника | `POST /employee` | `POST /api/v1/employees/` (поиск по глобальному справочнику) |
| Редактирование сотрудника | `PATCH /employee/:id` | `PUT /api/v1/employees/{employee_id}` |
| Удаление сотрудника | `DELETE /employee/:id` | `DELETE /api/v1/employees/{employee_id}` (soft delete) |
| Календарь | `GET /calendar?object_id=:id` | `GET /api/v1/shifts/calendar?workplace_id=...` |
| Добавление смены | `POST /calendar/:date/shift` | `POST /api/v1/shifts/` |
| Редактирование смены | отсутствовало | `PUT /api/v1/shifts/{shift_id}` |
| Удаление смены | `DELETE /calendar/:date/shift/:shift_id` | `DELETE /api/v1/shifts/{shift_id}` |
| Размножение смен | `POST /calendar/shifts/copy` | Исключено из MVP |
| Отчетность | отсутствовала | `GET /api/v1/reports/monthly` |
