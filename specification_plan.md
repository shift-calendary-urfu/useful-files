## Спринт 1

---

### 1. Спецификация Backend

Нужно определить:

1. **Модели БД**
   * какие сущности есть;
   * поля каждой сущности;
   * типы полей;
   * обязательность;
   * связи между моделями.

2. **Эндпоинты API**

   * `METHOD + URL`;
   * назначение;
   * входные параметры / body;
   * что возвращает;

Например:

`POST /employees`

* принимает: `name`, `workplace_id`
* возвращает: созданного сотрудника

---

### 2. Спецификация Frontend (сайт в браузере / PWA)

Нужно определить:

1. **Страницы**

   * какие страницы нужны;
   * URL каждой страницы;
   * для чего она нужна.

2. **Содержимое страниц**

   * какие данные отображаются;
   * какие таблицы/карточки/календарь;
   * какие кнопки и формы.

3. **Действия пользователя**

   * что пользователь может сделать на странице;
   * какие формы открываются;
   * какие данные вводятся;
   * что происходит после действия.

4. **Навигация**

   * как пользователь переходит между страницами;
   * какие страницы доступны из каких.

5. **Связь с Backend (После спецификации бекэнда)**

   * какой API-эндпоинт используется для каждого действия;
   * какие данные отправляются;
   * какие данные отображаются после ответа.

---
## Важно

**Достаточно сделать черновик по каждому пункты, чтобы было приблизительно понятно над чем работать. Кратко, но по делу!**

---

То есть совсем кратко:

**Backend:**

> **Модели -> поля -> связи -> API -> запросы -> ответы**

**Frontend:**

> **Страницы -> содержимое -> действия -> формы -> состояния -> навигация -(потом)> связь с API**
